# 地域創生支援アプリ フロントエンド開発仕様書

## 1. プロジェクト概要とルール

- **目的**: 地域課題を統計データで分析し、似た傾向を持つ地域や解決事例を提示する Web アプリの開発。
- **技術構成**:
  - **Backend**: Django (Python)
  - **Frontend**: Django Templates (HTML), CSS, ArcGIS API for JavaScript (地図部分のみ)
- **ディレクトリ構成ルール**:

  ```text
  app/
  ├── templates/app/    <-- HTMLファイルはここ
  ├── static/app/       <-- CSS/画像ファイルはここ
  └── views.py          <-- データ受け渡し（バックエンド担当領域）
  ```

- **開発の進め方**:
  - バックエンドと並行開発するため、HTML 作成時は**ダミーの文字や画像**を入れて見た目を作ってください。
  - 変数（`{{ variable }}`）を埋め込む場所だけ意識しておけば OK です。

---

## 2. 共通レイアウト (`base.html`)

全ページで共通して使用するヘッダー、フッター、CSS 読み込みを管理するファイル。

- **要件**:
  - アプリのタイトルロゴ（またはテキスト）をヘッダーに配置。
  - 全ページ共通の CSS ファイルを読み込むタグを記述。
  - 各ページのメインコンテンツが入る `{% block content %}` ブロックを定義。

## 3. 各ページ詳細仕様

### ① 地域選択トップページ

ユーザーが分析の起点となる地域を選ぶページ。

- **ファイル名**: `index.html`
- **URL**: `/`
- **必要な UI 要素**:
  - **タイトル**: 「分析を開始する地域を選んでください」
  - **検索フォーム**:
    - 都道府県・市区町村を選べるプルダウン、または検索可能なセレクトボックス。
    - （とりあえず全地域のリストが表示される `<select>` タグで OK）
  - **実行ボタン**: 「分析する」ボタン。押すと ② 分析結果ページ へ遷移。
- **受け取るデータ (Context)**:
  - `regions`: 全ての地域リスト（ID と名前を持つ）

### ② 分析結果ダッシュボード

選択した地域の現状（人口減少や課題）を可視化するページ。

- **ファイル名**: `analysis.html`
- **URL**: `/analysis/<int:region_id>/`
- **必要な UI 要素**:
  - **地域名表示**: 選んだ地域名を大きく表示。
  - **統計グラフ**: 人口推移などのグラフ画像を表示する `<img>` タグ。
  - **重要指標**: 最新の「人口」「空き家率」などの数値をカード形式で表示。
  - **次へのアクション**: 「似た課題を持つ地域を探す（類似地域へ）」ボタン。
- **受け取るデータ (Context)**:
  - `region_name`: 地域名
  - `stats`: 最新の統計データ辞書（人口, 空き家率など）
  - `graph_image`: グラフ画像のパス

### ③ 類似地域・解決事例リスト

AI ロジックにより算出された「似ている地域」をリスト表示するページ。

- **ファイル名**: `similar.html`
- **URL**: `/similar/<int:region_id>/`
- **必要な UI 要素**:
  - **タイトル**: 「〇〇市と似ている地域・解決事例」
  - **類似地域リスト**:
    - スコアが高い順にカードまたはリストで表示。
    - 各カードには「地域名」「類似度スコア」「簡単な特徴」を表示。
  - **マップボタン**: 「地図（ヒートマップ）で見る」ボタン。押すと ④ ヒートマップページ へ遷移。
- **受け取るデータ (Context)**:
  - `similar_regions`: 類似地域のリスト（名前、スコアを含む辞書の配列）

## 4. 【ArcGIS 担当向け】ヒートマップページ仕様

全国地図上に、類似度スコアに応じた色塗り（ヒートマップ）を表示するページ。

- **ファイル名**: `heatmap.html`
- **URL**: `/heatmap/<int:region_id>/`
- **フロントエンドの役割**:
  - ページ読み込み時に、JavaScript で下記の**API**を叩く。
  - 返ってきた GeoJSON データを ArcGIS API で描画する。
  - `score` の値が高いほど赤く、低いほど青く表示する等のスタイリングを行う。

### ★ バックエンドが提供する API 仕様

ArcGIS 担当者はこのデータを JavaScript で受け取って処理してください。

- **Endpoint**: `GET /api/heatmap/<int:region_id>/`
- **Response (GeoJSON 形式)**:

  ```json
  {
    "type": "FeatureCollection",
    "features": [
      {
        "type": "Feature",
        "properties": {
          "name": "A市",
          "score": 0.95  // この値で色分けする (0.0 ~ 1.0)
        },
        "geometry": {
           // 市区町村のポリゴン座標データ
           "type": "Polygon",
           "coordinates": [...]
        }
      },
      ...
    ]
  }
  ```
