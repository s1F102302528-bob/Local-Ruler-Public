# Local-Ruler

「地方創生」をテーマに企画されたチーム実習の成果物です。

## デモの動かし方

Windows環境のPython 3.12及びPython3.14.4にて動作を確認しています。環境構築のため、pipがインストールされている必要があります。

リポジトリをクローンしたら、venv等で仮想環境を作り、setup.batの内容を実行することで動作環境が整います。非Windows環境でうまく動かない場合はご相談ください。

セットアップが完了したら、Windows環境の場合、リポジトリルートから`py manage.py runserver`を実行してDjangoサーバーを起動することで、localhostからアクセスできるはずです。
